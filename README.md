# Clima SP

Análise de dados meteorológicos da cidade de São Paulo (outubro de 2026), com foco em chuva e temperatura para apoiar a rotina de entregadores de aplicativo.

## Estrutura do projeto

- `dados/bruto`: arquivos originais sem alteração
- `dados/tratado`: dados limpos prontos para consulta
- `scripts`: códigos em Python para coleta e organização
- `sql`: consultas analíticas feitas no DuckDB
- `docs`: anotações e relatório da atividade 1

## Ferramentas

- Python
- DuckDB
- Git e GitHub
